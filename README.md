## Tasks Overview

### SCT_PE_1 - Writing Better Prompts

Learn the fundamentals of prompt engineering by rewriting 3 vague prompts into precise, effective versions. Covers clarity, specificity, and tone. Includes side-by-side output comparisons and an analysis of how each design decision changes LLM behavior.

Folder: [SCT_PE_1](./SCT_PE_1/README.md)

---

### SCT_PE_2 - Prompting for Creativity

Explore how prompt structure, tone, and few-shot examples influence creative outputs. Runs 4 variants of a startup idea generation prompt and compares them across tone, creativity, detail, and usefulness. Demonstrates the power of persona-driven prompting.

Folder: [SCT_PE_2](./SCT_PE_2/README.md)

---

### SCT_PE_3 - Prompting for Task Automation

Design a production-grade prompt that converts raw meeting notes into structured JSON. Includes 4 input-output examples covering informal standups, formal project reviews, sparse notes, and multi-team sessions. Documents 4 iterations of prompt debugging and the lessons learned at each stage.

Folder: [SCT_PE_3](./SCT_PE_3/README.md)

---

### SCT_PE_4 - Simulating an Assistant

Build TechPrep, a persona-driven technical interview coach that adapts across conversation turns. Includes the full system prompt, a prompt chain flow diagram, two complete conversation logs (strong candidate and struggling candidate), and a detailed log of improvements made during development.

Folder: [SCT_PE_4](./SCT_PE_4/README.md)

---

## Key Concepts Covered

- Zero-shot, few-shot, and persona-driven prompting
- Prompt clarity, specificity, and tone calibration
- Structured output generation (JSON schema enforcement)
- Multi-turn dialogue and context management
- Prompt iteration and debugging methodology
- Hallucination prevention through explicit constraints
